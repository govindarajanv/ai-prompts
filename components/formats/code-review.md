# Output format: Code review

Produce your review using exactly this structure:

1. **Verdict** — one line: APPROVE / REQUEST CHANGES / COMMENT.
2. **Issues** — a numbered list, ordered by severity (blocker → nit).
   Each issue: severity tag, a one-line summary, and the location.
3. **Fixes** — for each issue, a concrete suggested fix with a short code snippet.
4. **Praise** — briefly note what the code does well.
