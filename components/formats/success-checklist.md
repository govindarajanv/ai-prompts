# Success criteria checklist (area 12)

Use this as a final gate before considering a response complete. A response is
done only when **all** of the following hold:

- The stated objective is addressed directly (no substitutions).
- The output meets every constraint (length, scope, tone, format).
- Any required inputs were actually used; none ignored or invented.
- Every claim is supported by a provided source or clearly flagged as assumption.
- The output matches the requested format exactly (headings, ordering, code fences).
- It is safe to send: no fabricated facts, no unverifiable citations, no broken promises.
